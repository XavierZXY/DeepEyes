## 1️⃣ tool_psnr_improvement.png - 工具PSNR改进对比

### 📊 图表类型
横向条形图（Horizontal Bar Chart）

### 🎯 显示内容
- **X轴**: PSNR改进量（单位：dB）
- **Y轴**: 工具名称
- **条形长度**: 平均PSNR改进
- **颜色**: 
  - 🟢 绿色 = 改进（正值）
  - 🔴 红色 = 变差（负值）
- **黑色虚线**: 0线（无改变）

### 📖 如何解读

**示例图表**:
```
restormer_motion_deblurring  |████████      | +3.5 dB (绿色)
fbcnn_jpeg_artifact_removal  |██████        | +2.1 dB (绿色)
mprnet_denoising            -|██            | -0.8 dB (红色)
xrestormer_deraining        -|██████        | -2.3 dB (红色)
                              0 dB
```

**解读**:
- ✅ **绿色长条**: 工具有效，能改进图像质量
- ❌ **红色长条**: 工具反而降低了质量
- 📏 **条形越长**: 改进/变差越明显
- 🏆 **最上方的工具**: 平均表现最好

**典型场景**:
- 如果大多数工具是绿色 → 数据集退化较重，工具有用
- 如果大多数工具是红色 → 数据集退化较轻，工具引入失真
- 绿色和红色混杂 → 工具针对性强，只对特定退化有效

## 2️⃣ tool_improvement_distribution.png - 改进量分布

### 📊 图表类型
箱线图（Box Plot），3个子图合一

### 🎯 显示内容
**3个子图**:
1. **上图**: PSNR改进分布
2. **中图**: SSIM改进分布
3. **下图**: LPIPS改进分布

**箱线图元素**:
- 📦 **箱体**: 中间50%的数据（第25-75百分位）
- ━━ **中线**: 中位数（第50百分位）
- ┬ **上须**: 最大值（不含异常值）
- ┴ **下须**: 最小值（不含异常值）
- ○ **圆点**: 异常值
- ━━ **红色虚线**: 0线（无改变）

### 📖 如何解读

**箱线图示例**:
```
        ○                     异常值（特别好的表现）
        ┬                     上须（最大值）
    ┌───┐
    │   │                     箱体（中间50%）
    │━━━│                     中线（中位数）
    │   │
    └───┘
        ┴                     下须（最小值）
        ○                     异常值（特别差的表现）
```

**关键指标**:
1. **箱体位置**:
   - 在0线上方 → 大多数情况下改进 ✅
   - 在0线下方 → 大多数情况下变差 ❌
   - 横跨0线 → 有时改进有时变差 ⚠️

2. **箱体高度**:
   - 箱体窄 → 稳定（表现一致）✅
   - 箱体宽 → 不稳定（表现差异大）⚠️

3. **须线长度**:
   - 须线短 → 范围小，可预测
   - 须线长 → 范围大，极端情况多

4. **异常值**:
   - 异常值多 → 有特殊情况
   - 无异常值 → 表现稳定

**实际示例**:
```
Tool A: ┌─┐      (箱体在+2到+5之间，稳定，都是改进)
        │━│      
        └─┘
        
Tool B:   ○      (箱体横跨0线，不稳定)
        ┌─┐
        │━│
        └─┘
        ○
```

**解读**:
- Tool A: 稳定可靠，总是改进 ✅
- Tool B: 不稳定，有时好有时差 ⚠️

## 3️⃣ degradation_heatmap.png - 退化类型热力图

### 📊 图表类型
热力图（Heatmap）

### 🎯 显示内容
- **X轴**: 退化类型（noise, blur, rain等）
- **Y轴**: 工具名称
- **颜色**: PSNR改进量
  - 🟢 深绿色 = 大幅改进（如+10 dB）
  - 🟡 黄色 = 小幅改进/无改变（0 dB左右）
  - 🔴 深红色 = 大幅变差（如-10 dB）
- **数字**: 每个格子显示具体的PSNR改进值

### 📖 如何解读

**示例热力图**:
```
                    noise  blur   rain   jpeg
swinir_denoising    +8.5  -2.1   -3.4   +0.5
                    🟢    🔴     🔴     🟡
                    
restormer_deraining -1.2  -0.8   +7.3   -2.0
                    🔴    🔴     🟢     🔴
                    
fbcnn_jpeg_removal  +0.3  -1.5   -2.1   +9.2
                    🟡    🔴     🔴     🟢
```

**关键观察**:
1. **对角线/聚集模式**:
   - 每个工具在对应退化上是绿色 → ✅ 工具专业性强
   - 工具在所有退化上都是黄绿色 → 通用工具
   - 大片红色 → 工具不适合该任务

2. **寻找最佳组合**:
   - 找一列（退化类型）中最绿的格子 → 该退化的最佳工具
   - 找一行（工具）中最绿的格子 → 该工具最擅长的退化

3. **工具选择策略**:
   - 如果只有一个绿色格子 → 专业工具
   - 如果多个绿色格子 → 通用工具
   - 如果全是红色 → 工具不适合此数据集

**实际应用**:
- 📌 一眼看出：`swinir_denoising` 最适合 `noise`
- 📌 一眼看出：`restormer_deraining` 最适合 `rain`
- 📌 一眼看出：`fbcnn_jpeg_removal` 最适合 `jpeg`

## 4️⃣ baseline_vs_restored.png - 退化图vs修复图对比

### 📊 图表类型
散点图（Scatter Plot），3个子图合一

### 🎯 显示内容
**3个子图**:
1. **左图**: PSNR对比
2. **中图**: SSIM对比
3. **右图**: LPIPS对比

**图表元素**:
- 🔵 **蓝点**: 每个测试（样本×工具）
- 🔴 **红色虚线**: y=x线（无改变线）
- **X轴**: 退化图的指标
- **Y轴**: 修复图的指标

### 📖 如何解读

**理想情况**（改进）:
```
修复图 ↑
    │     ○ ○ ○ ○     点在红线上方
    │   ○ ○ ○         = 修复后变好
    │ ○ ○             
    │○━━━━━━━━━→ 退化图
           红线 y=x
```

**糟糕情况**（变差）:
```
修复图 ↑
    │━━━━━━━━━         
    │     ○ ○ ○        点在红线下方
    │   ○ ○            = 修复后变差
    │ ○ ○              
    └──────────→ 退化图
       红线 y=x
```

**关键位置**:
1. **点在红线上** → 修复图 = 退化图（无改变）
2. **点在红线上方** → 修复图 > 退化图（改进）✅
3. **点在红线下方** → 修复图 < 退化图（变差）❌

**分布模式**:
- 所有点聚集在右上角 → 退化轻微，工具效果有限
- 点分散在各处 → 退化程度不一
- 点从左下到右上的斜向分布 → 工具有效果

**PSNR图解读**:
```
50 dB ↑                    ○ (高质量退化图，工具效果有限)
      │        ○○○
      │    ○○○○   
30 dB │  ○○○            (中等退化，工具有明显效果)
      │○○
10 dB │○                 (严重退化，工具大幅改进)
      └──────────────→
       10   30   50 dB
       退化图PSNR
```

**SSIM图解读**:
- 右上角（接近1.0） → 退化轻微
- 左下角（接近0） → 退化严重
- 点向右上移动 → 工具有效

**LPIPS图解读** (注意：越低越好):
- 点在红线下方 → 修复后LPIPS更低 → 改进 ✅
- 点在红线上方 → 修复后LPIPS更高 → 变差 ❌

## 5️⃣ success_rate_pie.png - 成功率饼图

### 📊 图表类型
饼图（Pie Chart）

### 🎯 显示内容
- **每个扇区**: 一个工具
- **扇区大小**: 该工具的成功率占比
- **颜色**:
  - 🟢 绿色: 成功率 > 95%（非常可靠）
  - 🟠 橙色: 成功率 80-95%（较可靠）
  - 🔴 红色: 成功率 < 80%（不可靠）
- **百分比**: 显示在扇区内

### 📖 如何解读

**理想状态**（全绿色）:
```
         ┌─────┐
     ┌───┤ 25% │ restormer (绿色)
 ┌───┤   └─────┘
 │20%│           
 └───┤   ┌─────┐
     └───┤ 30% │ mprnet (绿色)
         └─────┘
```
所有工具都是绿色 → 所有工具都很可靠 ✅

**有问题**（有红色）:
```
         ┌─────┐
     ┌───┤ 25% │ tool_A (绿色)
 ┌───┤   └─────┘
 │15%│ (红色)   ← 这个工具经常失败
 └───┤   
     └───┤ 60% │ tool_B (绿色)
         └─────┘
```
有红色扇区 → 该工具不稳定 ⚠️

**关键指标**:
- **绿色占比 > 80%**: 系统整体可靠 ✅
- **红色占比 > 20%**: 有工具不稳定，需要检查 ⚠️

**使用场景**:
1. 快速识别不稳定的工具
2. 评估测试的整体质量
3. 决定是否需要重新测试某些工具

## 📊 综合分析流程

### Step 1: 查看热力图 (degradation_heatmap.png)
**目的**: 找出工具和退化的最佳匹配

**操作**:
1. 找一列（退化类型），看哪个格子最绿
2. 记下最佳工具

**示例**:
- noise列: swinir_denoising最绿 → 最佳去噪工具
- rain列: restormer_deraining最绿 → 最佳去雨工具

### Step 2: 查看条形图 (tool_psnr_improvement.png)
**目的**: 评估工具的整体表现

**操作**:
1. 看最长的绿色条 → 整体最佳工具
2. 看最长的红色条 → 整体最差工具

### Step 3: 查看箱线图 (tool_improvement_distribution.png)
**目的**: 评估工具的稳定性

**操作**:
1. 找箱体最窄的 → 最稳定的工具
2. 找须线最短的 → 最可预测的工具
3. 找异常值最少的 → 最可靠的工具

### Step 4: 查看散点图 (baseline_vs_restored.png)
**目的**: 了解整体改进趋势

**操作**:
1. 看点的分布位置
2. 点在红线上方多 → 整体有改进
3. 点在红线下方多 → 整体变差

### Step 5: 查看饼图 (success_rate_pie.png)
**目的**: 检查测试可靠性

**操作**:
1. 确认绿色占比 > 80%
2. 如果有红色，检查对应工具的问题

## 🔍 常见模式识别

### 模式1: 理想的专业工具
- ✅ 热力图: 一个深绿格子，其他都是红/黄
- ✅ 条形图: 绿色或小红色
- ✅ 箱线图: 箱体窄（稳定）
- **示例**: MPRNet去噪对noise (+11.77dB对口，-6.07dB非对口)

### 模式2: 通用但不精的工具
- 🟡 热力图: 多个浅绿/黄色格子
- 🟡 条形图: 短绿条或接近0
- 🟡 箱线图: 横跨0线
- **特点**: 对各种退化都有一点效果，但不突出

### 模式3: 不适合的工具
- ❌ 热力图: 大片红色
- ❌ 条形图: 长红条
- ❌ 箱线图: 全在0线下方
- **特点**: 对此数据集无效或有害

### 模式4: 轻度退化数据集
- 📍 散点图: 点聚集在右上角（高PSNR/SSIM，低LPIPS）
- 📍 条形图: 大多数是红色（工具反而降低质量）
- **说明**: 退化太轻，接近原图，工具处理反而引入失真
