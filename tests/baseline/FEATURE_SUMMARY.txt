📊 总体统计指标（已实现）
================================================================================

对于每个策略，现在提供以下统计：

1. 基本统计
   ✅ Mean (平均值) - 总体趋势
   ✅ Std (标准差) - 稳定性评估 ⭐ 新增
   ✅ Median (中位数) - 典型表现 ⭐ 新增
   ✅ Min (最小值) - 最差情况 ⭐ 新增  
   ✅ Max (最大值) - 最佳情况 ⭐ 新增

2. 质量指标（三种）
   ✅ PSNR - 退化图vs原图，修复图vs原图
   ✅ SSIM - 退化图vs原图，修复图vs原图
   ✅ LPIPS - 退化图vs原图，修复图vs原图

3. 成功率统计
   ✅ Tool Success Rate - 工具调用成功比例 ⭐ 新增
   ✅ 成功步数/总步数

4. 分组统计
   ✅ 按退化类型分组 ⭐ 新增
   ✅ 每种退化的修复效果
   ✅ 不同策略在特定退化上的表现

5. 策略对比
   ✅ RANDOM vs REVERSE 自动对比 ⭐ 新增
   ✅ 自动判断优胜者
   ✅ 显示差异值和意义

================================================================================
📁 输出文件（5个统计文件）
================================================================================

运行测试后，在results/目录生成：

1. summary_<timestamp>.txt
   - 总体统计摘要
   - 包含所有新增指标
   - 策略对比摘要
   
2. detailed_stats_<timestamp>.txt ⭐ 新增
   - 按退化类型的详细统计
   - 每种退化在不同策略下的表现
   - 退化类型修复难度排序

3. statistics_<timestamp>.csv ⭐ 新增
   - CSV格式的总体统计
   - 列：strategy, metric, mean, std, median, min, max, samples
   - 便于Excel/pandas分析

4. by_degradation_<timestamp>.csv ⭐ 新增
   - CSV格式的分组统计
   - 列：degradation_type, strategy, metric, mean_improvement, sample_count
   - 便于数据透视和可视化

5. results_<timestamp>.json
   - 所有样本的原始详细数据
   - 包含修复日志等

📊 使用pandas分析示例

# 读取并分析统计数据
python3 << 'PYEOF'
import pandas as pd
import numpy as np

# 1. 读取总体统计
stats = pd.read_csv('results/statistics_20251015_123456.csv')
print("总体统计：")
print(stats)

# 2. 策略对比
print("\n策略对比（PSNR）：")
psnr_data = stats[stats['metric'] == 'psnr']
for _, row in psnr_data.iterrows():
    print(f"  {row['strategy']}: {row['mean']:.4f} ± {row['std']:.4f}")

# 3. 按退化类型分析
deg_stats = pd.read_csv('results/by_degradation_20251015_123456.csv')
print("\n各退化类型的平均改善（PSNR）：")
psnr_by_deg = deg_stats[deg_stats['metric'] == 'psnr']
avg_by_deg = psnr_by_deg.groupby('degradation_type')['mean_improvement'].mean()
print(avg_by_deg.sort_values(ascending=False))

# 4. 找出最需要改进的
print("\n需要重点改进的退化类型：")
print(avg_by_deg.sort_values().head(3))

🎯 关键指标说明
================================================================================

Mean (平均值):
  - 所有样本的算术平均
  - 反映总体趋势
  - 会受极端值影响

Std (标准差):
  - 数据的离散程度
  - 值越小越稳定
  - 大标准差表示结果不一致

Median (中位数):
  - 排序后的中间值
  - 不受极端值影响
  - median > mean 说明有拖后腿的样本

Min/Max:
  - 极端情况的表现
  - Min < 0 表示有变差的样本
  - Max显示最佳可能效果

Success Rate:
  - 工具调用成功的比例
  - >95% 良好
  - <90% 需要检查工具服务
