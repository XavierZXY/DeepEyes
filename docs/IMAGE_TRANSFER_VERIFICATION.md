
## 📊 理论依据

### Python 列表索引特性

```python
history = [img0, img1, img2]

# [-1] 总是取最后一个元素
history[-1]  # → img2

# append 添加到末尾
history.append(img3)
# 现在：history = [img0, img1, img2, img3]

# 下次 [-1] 就会取到 img3
history[-1]  # → img3
```

这是 Python 的基础特性，100% 可靠！
