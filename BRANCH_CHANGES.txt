✅ 1. 验证错误样本上传到 Wandb
   
   在验证阶段自动上传预测错误的样本，包含：
   • 原图、退化图、复原图（纯净PNG，分开存储）
   • 真实标签、预测标签、漏检、误检
   • 图像质量指标（SSIM/LPIPS/PSNR）
   • 图片路径（方便后处理）
   
   Wandb 查看位置：
   • Tables → val_errors/wrong_predictions  (表格)
   • Media → val_error_images/              (图片)
   • Charts → val_errors/error_rate         (统计)


✅ 2. LPIPS GPU 加速优化（性能提升 50x）
   
   修复了之前 GPU 使用报错的问题，并大幅提升性能：
   • CPU: 1088 ms/image → GPU: 22 ms/image
   • 加速比：50x
   
   同时优化：
   • CLIP 模型：移到 GPU
   • PyIQA 模型：在 GPU 上初始化
